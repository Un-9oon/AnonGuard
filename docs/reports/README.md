# Historical research and review notes

Files in this directory are non-normative records of earlier designs, hypotheses,
simulations and reviews. Some contain incorrect or overstated claims, obsolete
cell layouts, retired paths or unvalidated audit conclusions. Their warning
headers are intentional: they must not be presented as current results.

For implemented behavior use [v6](../PROTOCOL_V3.md),
[architecture](../architecture.md) and [readiness gates](../PRODUCTION_READINESS.md).
Dated evidence elsewhere applies only to its recorded source/configuration.
Retaining a historical report is not an endorsement of its claims.
